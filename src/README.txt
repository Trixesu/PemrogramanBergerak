TUGAS PEMROGRAMAN DASAR KOTLIN

Berisi 15 program sesuai lembar tugas:
A. Tipe Data       : 01 - 05
B. Variabel        : 06 - 10
C. Fungsi          : 11 - 15

Petunjuk:
1. Setiap file .kt merupakan satu tugas.
2. Jalankan masing-masing file menggunakan Kotlin/IntelliJ IDEA.
3. Ambil tangkapan layar hasil eksekusi untuk bukti pengumpulan.
4. Upload kode ke GitHub pada branch sesuai NIM.
